- **Auditor:** Antigravity AI (Anti Slop Engine)

## Executive Summary

An audit of the codebase (`src/`, `App.vue`, stores, components, rules, and styles) identified **14 findings** across all antislop rule tiers:
- **Hard Gate (HIGH):** 6 findings (Copywriting em dashes, Modal keyboard escape, Mobile tap targets, Color contrast, Missing UI states, Missing DESIGN.md direction)
- **Purpose-Gate (MEDIUM):** 5 findings (AI lightning/sparkle iconography, Feature card uniformity, Dark mode toggle justification, Glassmorphism stacking, AI capsule badges)
- **Quality Locks & Hygiene (LOW):** 3 findings (Decorative banner comments, Restating obvious comments, Dead code template leftovers)

Under Mode 2 rules, **no source code has been modified**. Review the numbered list below and select which finding numbers you approve for remediation.

## Numbered Findings List

### [HIGH Priority - Hard Gate Violations]

#### 1. R-02 Copywriting: Forbidden em dash (`—`) character in tactical warnings
- **Violated Rule:** `R-02` (Copywriting)
- **One-line Reason:** The em dash (`—`) is used in combat tactical warning banners instead of hyphens, colons, or parentheses.
- **Location:** [`src/components/sheet/TargetedAttacksList.vue:L39`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/components/sheet/TargetedAttacksList.vue#L39), [`src/components/sheet/TargetedAttacksList.vue:L43`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/components/sheet/TargetedAttacksList.vue#L43)
- **Remediation:** Replace `—` with `:` or standard hyphen `-`.

#### 2. R-32 Keyboard Accessibility: Modals lack `Escape` key close handler
- **Violated Rule:** `R-32` (Keyboard Accessibility)
- **One-line Reason:** None of the modal dialogs listen for the `Escape` key to dismiss, requiring a mouse click to close.
- **Location:** [`src/components/modals/ExportImportModal.vue`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/components/modals/ExportImportModal.vue), [`src/components/modals/ShareModal.vue`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/components/modals/ShareModal.vue), [`src/components/modals/Roll20PrintModal.vue`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/components/modals/Roll20PrintModal.vue), [`src/components/power-studio/PowerStudioModal.vue`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/components/power-studio/PowerStudioModal.vue)
- **Remediation:** Add a global `keydown` handler listening for `Escape` to close the active modal via `uiStore.closeModal()`.

#### 3. R-03 Mobile Responsiveness: Interactive stepper buttons far below 44px tap target standard
- **Violated Rule:** `R-03` (Mobile Responsiveness)
- **One-line Reason:** Stepper buttons like `.step-btn-xs` (24x24px) and `.step-btn` (30x30px) fall well below the 44px touch target minimum.
- **Location:** [`src/styles/sheet.css:L174-189`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/styles/sheet.css#L174-L189), [`src/styles/sheet.css:L1005-1018`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/styles/sheet.css#L1005-L1018), [`src/styles/sheet.css:L1085-1094`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/styles/sheet.css#L1085-L1094)
- **Remediation:** Increase touch target sizes or add pseudo-element hitboxes (`::after` expanding touch area to >= 44x44px on touch devices).

#### 4. R-25 Color Contrast: Sub-standard contrast on `--text-muted` and input placeholders
- **Violated Rule:** `R-25` (Color Contrast) & `antislop-human`
- **One-line Reason:** `--text-muted: #71717a` against dark background `--bg-app: #09090b` yields a 4.12:1 contrast ratio, failing the WCAG AA 4.5:1 minimum for regular text.
- **Location:** [`src/styles/main.css:L20`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/styles/main.css#L20), [`src/styles/main.css:L98`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/styles/main.css#L98)
- **Remediation:** Adjust `--text-muted` to at least `#9ca3af` (Zinc-400, contrast 6.9:1) to exceed WCAG AA requirements.

#### 5. R-27 UI States: Missing initial application loading state and Vue error boundaries
- **Violated Rule:** `R-27` (UI States)
- **One-line Reason:** `index.html` has only an empty `<div id="app"></div>`; if JavaScript fails to parse or initialize, the user gets an unresponsive black screen with zero user feedback.
- **Location:** [`index.html:L16`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/index.html#L16), [`src/App.vue`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/App.vue)
- **Remediation:** Add an initial loading spinner inside `#app` before hydration, and wrap main views in `onErrorCaptured` with an error state screen.

#### 6. R-37 Design Direction: Missing `DESIGN.md` specification and divergence from `demiplane.com-design.md`
- **Violated Rule:** `R-37` (Design Direction Required) & `R-31`
- **One-line Reason:** The repository contains `demiplane.com-design.md` (which prescribes sapphire blue `#006fb8` and Barlow/Roboto), but the codebase diverged into Signal Crimson (`#e11d48`) and Geist/Geist Mono without a `DESIGN.md` documenting this direction.
- **Location:** [`demiplane.com-design.md`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/demiplane.com-design.md), [`src/styles/main.css:L23`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/styles/main.css#L23)
- **Remediation:** Create a formal `DESIGN.md` establishing the design tokens, dials (`ENERGY 2 / RHYTHM 2 / MOTION 1`), and typographic voice.

### [MEDIUM Priority - Purpose-Gate Violations]

#### 7. R-04 Icons: Ubiquitous generic AI lightning and sparkle iconography
- **Violated Rule:** `R-04` (Icons)
- **One-line Reason:** AI lightning (`ri-flashlight-fill` / `ri-flashlight-line`) is used in over 43 locations as the catch-all for App Logo, Powers tab, Hero Point reroll, auto-sync, and KV share links; and `ri-sparkling-line` (magic sparkle) is used for the Character Wizard.
- **Location:** [`src/App.vue:L8`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/App.vue#L8), [`src/App.vue:L30`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/App.vue#L30), [`src/components/sheet/TabbedActionHub.vue:L24`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/components/sheet/TabbedActionHub.vue#L24)
- **Remediation:** Replace generic lightning and sparkles with semantically relevant tabletop gaming icons (e.g. superhero d20 motif or shield emblem for logo, superhero mask/cape for powers, wand/scroll for wizard, dice for rerolls).

#### 8. R-14 Feature Cards: Copy-paste repetitive internal card layout flattening hierarchy
- **Violated Rule:** `R-14` (Feature Cards)
- **One-line Reason:** All defense cards in `DefensesBlock.vue` use identical 2-column rectangular boxes with identical steppers, giving passive saving throws (Fortitude/Will) the exact same visual weight as active defenses (Dodge/Parry) and key survivability (Toughness).
- **Location:** [`src/components/sheet/DefensesBlock.vue:L10-165`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/components/sheet/DefensesBlock.vue#L10-L165)
- **Remediation:** Differentiate active defenses (Dodge & Parry grouped) from passive resistances (Fortitude & Will), with Toughness maintaining prominent primary status.

#### 9. R-21 Dark Mode: Fixed dark theme without light mode toggle or documented justification
- **Violated Rule:** `R-21` (Dark Mode)
- **One-line Reason:** The application forces `color-scheme: dark` with no light theme toggle, and without documented low-light tabletop session operational justification in `DESIGN.md`.
- **Location:** [`index.html:L1`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/index.html#L1), [`src/styles/main.css:L85`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/styles/main.css#L85)
- **Remediation:** Either provide a working light/dark mode toggle or document the GM tabletop low-light operational rationale in `DESIGN.md`.

#### 10. R-10 Glassmorphism: Trend-stacking backdrop-filter blur across simultaneous layers
- **Violated Rule:** `R-10` (Glassmorphism)
- **One-line Reason:** `backdrop-filter: blur(...)` is applied simultaneously on navbar (`App.vue:460`), modals, dropdown menus, and command banners, violating the dose cap of 1-2 elements.
- **Location:** [`src/App.vue:L460`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/App.vue#L460), [`src/styles/main.css:L42`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/styles/main.css#L42)
- **Remediation:** Use solid opaque/semi-opaque matte surfaces (`rgba(15, 23, 42, 0.96)`) for standard surfaces and reserve glassmorphism strictly for modal backdrops.

#### 11. R-09 Badges: AI capsule pill badges stacked with small dots and uppercase labels
- **Violated Rule:** `R-09` (Badges)
- **One-line Reason:** Pill-shaped badges with uppercase labels (`PL 10`, `1 PP / Rank`, `v1.0`, `FILE & STORAGE`) are heavily sprinkled across cards as visual filler.
- **Location:** [`src/App.vue:L12`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/App.vue#L12), [`src/App.vue:L92`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/App.vue#L92), [`src/components/sheet/DefensesBlock.vue:L5`](file:///c:/Users/Caniago/Downloads/Tes/mm3e-builder-vue/src/components/sheet/DefensesBlock.vue#L5)
- **Remediation:** Reduce decorative badge usage; replace uppercase filler labels with standard sentence-case text hierarchy.
